# WEBAPP-TAREAS

Aplicación web para la gestión de tareas diarias en tiendas.

## Características

- **Sistema multi-tienda**: Filtrado automático de tareas según la tienda seleccionada
- **Categorías de tareas**: Apertura, Mantenimiento y Cierre
- **Soporte para fotos**: Algunas tareas requieren foto como evidencia
- **Persistencia local**: Estado de las tareas guardado en localStorage
- **Diseño responsive**: Funciona en móviles y escritorio

## Instalación

```bash
npm install
npm run dev
```

## Uso

1. Selecciona tu nombre y tienda en la pantalla de configuración
2. Marca las tareas completadas
3. Sube fotos para las tareas que lo requieran

## Tecnologías

- React 19
- Vite
- CSS3
