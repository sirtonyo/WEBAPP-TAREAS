DOCUMENTACIÓN TÉCNICA - ZAPATERIAS PASTOR OPS
=============================================

1. CÓDIGOS DE RECURRENCIA (Columna E - Config_Tareas)
-----------------------------------------------------
Formato: String numérico (ISO-8601: 1=Lunes, 7=Domingo).

Ejemplos:
- "0"      -> DIARIO (Todos los días de la semana).
- "1"      -> Solo Lunes.
- "135"    -> Lunes, Miércoles y Viernes.
- "67"     -> Sábado y Domingo (Fin de semana).
- "123456" -> De Lunes a Sábado.
- "36"     -> Miércoles y Sábado.

IMPORTANTE: También se aceptan letras españolas (legacy):
- L=Lunes, M=Martes, X=Miércoles, J=Jueves, V=Viernes, S=Sábado, D=Domingo
- Ejemplo: "L,X,V" = Lunes, Miércoles, Viernes
- Se recomienda usar formato numérico para consistencia.

2. CATEGORÍAS (Columna D - Config_Tareas)
-----------------------------------------
Etiquetas usadas para agrupar visualmente por prioridad.
Valores permitidos (Case Sensitive - Respetar mayúsculas):

| Categoría  | Color Badge      | Descripción                      |
|------------|------------------|----------------------------------|
| "Mañana"   | Naranja/Ámbar    | Prioridad Alta - Inicio turno    |
| "Dia"      | Azul             | Mantenimiento recurrente         |
| "A fondo"  | Rosa/Magenta     | Limpiezas profundas puntuales    |
| "Cierre"   | Gris (default)   | Bloqueantes para irse a casa     |

3. LÓGICA DE FOTO (Columna G - Config_Tareas: requiresPhoto)
------------------------------------------------------------
- TRUE  -> La App requerirá foto (futuro feature).
- FALSE -> Checkbox libre.

4. CÓDIGOS DE TIENDA (Columna F - Config_Tareas: targetStores)
--------------------------------------------------------------
Formato: Lista separada por comas o "all".

| Código | Tienda           |
|--------|------------------|
| "T1"   | Tienda Colón     |
| "T2"   | Tienda Ruzafa    |
| "T3"   | Tienda [Nombre]  |
| "T4"   | Tienda [Nombre]  |
| "T5"   | Tienda Online    |
| "all"  | Todas las tiendas|

Ejemplos:
- "all"     -> Aplica a todas las tiendas
- "T1"      -> Solo Tienda Colón
- "T1,T3"   -> Solo Tiendas Colón y [Nombre]

URL de acceso: /?store=T1, /?store=T2, etc.

7. MAPEO DE ESTADOS (Logs)
--------------------------
| Estado             | Descripción                           |
|--------------------|---------------------------------------|
| "PENDING"          | Pendiente                             |
| "DONE"             | Realizada                             |

| Col | Header     | Descripción                    |
|-----|------------|--------------------------------|
| A   | Timestamp  | Fecha/hora del cambio          |

9. ATAJOS DE TECLADO (WebApp)
-----------------------------
| Tecla      | Acción                              |
|------------|-------------------------------------|
| ←→         | Navegar entre días (columnas)       |
| ↑↓         | Navegar entre tareas                |
| Enter      | Abrir modal de tarea seleccionada   |
| i          | Mostrar info/descripción de tarea   |
| Ctrl+C     | Cierre diario de tareas             |
| Alt+R      | Crear nuevo encargo (requiere PIN)  |
| Esc        | Cerrar modal abierto                |

Nota: Ctrl+C no aparece en leyenda UI (solo para responsables)
      Alt+R no aparece en leyenda UI (solo para responsables)

13. CIERRE DIARIO (Ctrl+C)
--------------------------
- Si todas las tareas del día están DONE:
  → Pide confirmación + firma empleado
  → Registra "CIERRE" en log

- Si hay tareas pendientes:
  → Muestra lista de tareas sin completar
  → Pide motivo para cada una
  → Pide firma empleado
  → Registra "CIERRE_INCOMPLETO" para cada tarea + "CIERRE" general
